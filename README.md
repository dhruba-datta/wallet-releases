# Mintwise downloads

Release files for **Mintwise**, a private money tracker for Android: accounts, records,
debts and templates, synced to its owner's own database.

- Requires an Android phone with a 64-bit processor (any phone from the last several years).
- Download `mintwise.apk` from the [latest release](../../releases/latest) and open it.
  The first time, Android asks you to allow installing apps from your browser or file app.
- Mintwise updates itself from here: open the menu → **Check for updates**.
- Signing in needs an account on the owner's server; sign-ups are closed.

This repository holds release files only.
